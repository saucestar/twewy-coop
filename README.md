# TWEWY Co-op

Mode co-op (J2) pour **TWEWY Solo Remix PC**. Ce dépôt ne contient aucun fichier du jeu :
l'installeur applique le mod à ta propre copie et garde l'original intact.

1. Télécharge **[TWEWY-Coop-Setup.exe](TWEWY-Coop-Setup.exe?raw=1)**
2. Choisis le dossier du jeu (celui qui contient `TWEWY Solo.exe`) → *Installer*
3. Lance **TWEWY Co-op** : les mises à jour te seront proposées dans l'onglet JOUER.

Dernière version : **1.7.1** — Installeur traduit en anglais (il suit la langue choisie dans le launcher, sinon celle de Windows).
